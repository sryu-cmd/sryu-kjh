# 매직박스2 — 1~2단계 전용

## 목적
기존 매직박스(1~4단계)의 3단계(클러스터 기반 중복제거)가 예측하기 어려운 새 문제를
계속 일으키고 있어, **1~2단계만 따로 떼어 충분히 검증**하기 위한 별도 버전입니다.

이 버전은 **3단계를 아예 실행하지 않습니다.** 결과물(H열)에는 같은 발언의 중복이
여러 형태로 그대로 남아있을 수 있는데, 이건 정상입니다 — 이 버전으로는
"인용문이 잘못된 화자에게 붙었는지(오류발췌)"와 "인용문이 통째로 빠졌는지(발췌누락)"만
확인하면 됩니다.

## 배포 방법 (기존 매직박스와 동일)
1. 이 폴더 전체를 **새로운** GitHub 저장소에 올린다 (기존 매직박스 저장소와는 별도로).
2. streamlit.io/cloud 에서 "New app" → 이 저장소 연결 → `app.py` 지정.
3. Streamlit Cloud 설정의 "Secrets"에 아래를 추가한다:
   ```
   TEAM_CREDENTIALS = '{"편집인1": "비밀번호1", "편집인2": "비밀번호2"}'
   ```
   (4단계가 없으므로 `ANTHROPIC_API_KEY`는 필요 없습니다.)
4. 배포되면 URL이 생성됩니다.

## 로컬 테스트
```
streamlit run app.py
```

## 나중에 3단계를 다시 연결하려면
기존 매직박스(1~4단계 전체)를 계속 쓰거나, 이 앱에 `stage3_cluster.py`를 추가하고
`app.py`에 3단계 호출 부분을 다시 넣으면 됩니다. 그전까지는 이 앱으로 1~2단계만
집중적으로 검증하는 것을 권장합니다.
