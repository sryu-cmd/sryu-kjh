# 발언 인용문 매직박스

동료들이 언제 어디서나 웹브라우저로 접속해 같은 프로그램·같은 AI로 작업할 수 있는 도구.

## 구성

- `app.py` — 웹앱 본체 (Streamlit)
- `stage1_core.py`, `stage2_group_v2.py`, `stage3_dedup.py` — 1~3단계 처리 로직
- `title_master_list.py` — 직함·정당명 등 마스터 목록 (새 인물 처리하다 빠진 게 있으면 여기에 추가)
- `stage4_system_prompt.txt` — 4단계 설명문 작성용 AI 프롬프트
- `regression_test.py` — 기존 5명 데이터로 회귀 테스트 (배포 전 항상 실행 권장)
- `requirements.txt` — 필요한 파이썬 패키지 목록

## 배포 방법 (개발자 없이 가능, 30분 이내)

1. **GitHub 저장소 만들기**: 이 폴더 전체를 private 저장소에 업로드합니다.
2. **Streamlit Community Cloud 접속**: https://streamlit.io/cloud 에서 GitHub 계정으로 로그인합니다.
3. **New app**: 방금 만든 저장소, `app.py`를 선택해 배포합니다.
4. **Secrets 설정** (앱 설정 -> Secrets):
   ```toml
   ANTHROPIC_API_KEY = "여기에 API 키"
   TEAM_CREDENTIALS = '{"편집인": "비밀번호1", "동료1": "비밀번호2", "동료2": "비밀번호3"}'
   ```
   (10명 이내이므로 JSON 형태로 아이디:비밀번호를 직접 나열하면 됩니다.)
5. 배포가 끝나면 `https://xxxx.streamlit.app` 같은 URL이 생깁니다. 이 URL과 각자의 아이디·비밀번호를 동료들에게 전달합니다.

## 업데이트 방법

코드를 수정한 뒤(예: `title_master_list.py`에 새 직함 추가) `regression_test.py`를 돌려
기존 5명 데이터가 그대로인지 확인합니다. 통과하면 GitHub에 push — Streamlit Cloud가
자동으로 재배포합니다. 동료들은 브라우저 새로고침만 하면 최신 버전을 씁니다.

## 사용 방법 (동료 입장)

1. 배포된 URL 접속 → 아이디·비밀번호 입력
2. 지정발언자 이름·성 입력, CSV 파일 업로드
3. "4단계까지 AI로 자동 작성" 체크 여부 선택
4. 실행 → 완료되면 결과 CSV 다운로드

## 두 가지 자체 점검 도구

이 도구들은 파이썬만 설치돼 있으면 **저 없이도, 언제든, 랜덤 인터벌로** 직접 돌리실 수 있습니다.

### 1) `regression_test.py` — 기존 인물이 여전히 맞는지 확인
코드를 고친 뒤(직함 추가 등) 기존 5명 데이터가 예전과 같은 결과를 내는지 자동 확인합니다.
```
python regression_test.py
```
"모두 통과" 또는 "불일치" 메시지가 나옵니다. 원본 CSV 5개 파일이 있어야 돌아갑니다.

### 2) `self_check.py` — 새 인물 파일에서 확인이 필요한 행만 골라줌
회귀 테스트와 다른 목적입니다. "예전 것이 안 깨졌나"가 아니라 "이 새 파일에 우리가 아직
못 본 새로운 패턴이 있나"를 빠르게 스크리닝합니다.
```
python self_check.py <새파일.csv> <이름> <성>
예: python self_check.py 이탄희_원본.csv 이탄희 이
```
- 인용문이 자동으로 제외된 행, "검토필요" 표시가 붙은 행, 2단계 미처리 건수를 콘솔에 요약하고
  `<이름>_자체점검.csv`로 저장합니다.
- 이 파일만 훑어보면 전체 CSV(수백~수천 행)를 다 안 읽어도 됩니다.
- **점검 필요 행이 0건이면**: 기존 규칙이 새 인물에도 잘 맞는다는 뜻입니다.
- **점검 필요 행이 있으면**: 그 행들만 읽고, 진짜 오류인지(규칙 보강 필요) 정상 동작인지(안전장치가
  맞게 작동) 판단하시면 됩니다. 규칙 보강이 필요하면 그 시점에 저와 상의하시면 됩니다.



- 2단계 "미처리"(편집 판단 필요) 건은 자동 처리되지 않고 그대로 남습니다. 현재는
  사람이 CSV를 열어 직접 병합/분절을 확정해야 합니다. (2B 단계 AI 자동화는 아직 미구현)
- 4단계 설명문은 배치(10건씩)로 API를 호출합니다. 대용량 파일은 시간이 걸릴 수 있습니다.
- 소유격 삽입절 필터의 "70% 이상 비중" 예외 케이스는 검토 표시만 남기고 자동 처리하지
  않습니다.
- 직함·정당명 목록은 계속 확장되고 있습니다. 새 인물 처리 중 "이상한 결과"가 나오면
  먼저 `title_master_list.py`에 빠진 직함이 없는지 확인하는 것이 첫 번째 점검 포인트입니다.
